# Security Policy

## Scope

This repository contains only generic, non-proprietary showcase code. No production integrations are included.

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it privately:

- LinkedIn: [https://www.linkedin.com/in/seanraynon/](https://www.linkedin.com/in/seanraynon/)
- Website contact: [https://kaoten.com](https://kaoten.com)

Please include:

- A clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Any suggested remediation

## Secure Contribution Expectations

- Never commit secrets, tokens, keys, or private credentials.
- Never add real customer or operational data.
- Keep all data synthetic and examples generic.
- Prefer explicit validation and fail-closed behavior in examples.
